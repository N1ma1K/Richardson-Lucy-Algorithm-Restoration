# Richardson-Lucy-Algorithm-Restoration
A small Python project exploring Richardson–Lucy deconvolution on astronomical FITS images obtained from the Mikulski Archive for Space Telescopes (MAST).
# Data

## Source
Mikulski Archive for Space Telescopes (MAST)

## Observation
Hubble Space Telescope image of M51
(the Whirlpool Galaxy).

## File
h_m51_b_s20_drz_sci.fits

## Download
https://archive.stsci.edu/prepds/m51/datalist.html

## Notes
The FITS file is stored locally and excluded from Git.
Download the file from the source above before running
the notebook.

Processing parameters and results are documented
in the experiment notebook.
